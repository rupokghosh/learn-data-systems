Learn Data Systems

This is an interactive companion to Designing Data-Intensive Applications by Martin Kleppmann. The book explains how databases, caches, queues, and distributed systems really work. This site lets you see those ideas move.

Each lesson is one page: a short explanation, followed by things you can change and watch. Grow a log until it needs compaction. Split a B-tree page. Let a celebrity post and see which timeline design falls over. The goal is not to memorize the book, but to build the intuition a good engineer uses when choosing and operating data systems.

Everything here is written fresh and only summarizes the book. Read the book for the full depth. This is an unofficial project, not affiliated with or endorsed by the author or the publisher.
